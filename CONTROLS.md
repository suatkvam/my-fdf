Multi-Projection FDF Controls:

🎮 MOVEMENT CONTROLS:
   W/A/S/D  - Move camera (Up/Left/Down/Right)
   Q/E      - Rotate left/right
   Mouse    - Zoom in/out with scroll wheel
   
🔄 PROJECTION MODES:
   P        - Cycle through projection types:
              1. Isometric (default 3D view)
              2. Perspective (realistic 3D with depth)
              3. Orthographic (technical drawing view)
              4. Top-Down (perfect for heightmaps/PNG)
              5. Front View (X-Z plane)
              6. Side View (Y-Z plane)
              
⚡ OTHER:
   ESC      - Exit program

📋 BEST PROJECTIONS FOR DIFFERENT USES:
   - Isometric: General 3D wireframe viewing
   - Perspective: Realistic 3D scenes, gaming view
   - Orthographic: Technical drawings, blueprints
   - Top-Down: PNG/image heightmaps, aerial view
   - Front/Side: Profile analysis, cross-sections
   
🚀 Enhanced with custom Math3D library for smooth transformations!
